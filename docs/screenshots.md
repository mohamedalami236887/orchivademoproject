# Screenshot checklist

No application screenshots are currently included. After starting the local backend and frontend, capture genuine application states in `docs/screenshots/` and then replace the checklist entries in the root README with real image links.

| Planned file | Capture |
| --- | --- |
| `dashboard.png` | Role-scoped dashboard with real workload and recent activity |
| `requests.png` | Requests collection with search, status views, filters, and selected inspector |
| `request-detail.png` | A request with real approval progress and supporting documents |
| `approval-inbox.png` | A pending manager task with selected workflow context |
| `workflow-studio.png` | A published workflow and selected stage in Workflow Studio |
| `audit-explorer.png` | Administrator audit history with one expanded event |

Use a consistent desktop viewport (for example 1440 × 900), then capture a mobile view where it adds useful evidence. Review each image for personal data, credentials, machine paths, and browser chrome before including it. Do not create fake approval tasks or fabricated data for portfolio media.
